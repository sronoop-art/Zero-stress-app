# Layout Studio (native companion app)

A tiny offline Android app that lets you redesign the ONLY TEAM-X look on
your phone: live previews of the login, dashboard and chat screens, 11
color controls, glass/border/radius sliders, presets and a randomizer.
It exports the exact `Theme.kt` / `ZsTheme.kt` files the real app uses.

## Build in AndroidIDE

1. Unzip `LAYOUT-STUDIO.zip` (or open the `studio-app` folder).
2. **No `google-services.json` needed** - this app has no Firebase.
3. Build the debug APK: **Build > Build Project(s)** / the hammer icon.
4. Install it. It appears as **"Layout Studio"** with a cyan X icon,
   next to ONLY TEAM-X (it does not modify or replace the game app).

## Using it

1. Tweak colors / sliders or tap a preset - the preview updates live.
   Your design is saved automatically on the device.
2. Tap **COPY THEME.KT**, come to the chat and paste it.
3. Tap **COPY ZSTHEME.KT**, paste that too.
4. The theme gets applied to the real app sources and a fresh
   `ZS3.1.zip` is built - install and enjoy.

SHARE / SAVE TO DOWNLOADS give you the same files as text if you prefer.
