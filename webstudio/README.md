# NEXUS Theme Studio

Live UI customizer for the ZERO STRESS Android app. Pick colors (or tap a
preset / randomize), watch the phone preview of the login, dashboard and chat
screens update in real time, then **COPY THEME.KT** and send the result back —
it drops straight into `app/src/main/java/com/zerostress/manager/ui/theme/`.

Open `theme-studio.html` (any static server works; `node server.js` included).
